# TaskFlow

A simple, single-page task management app.

## Stack

- React + Vite
- Plain CSS
- localStorage persistence (no backend)

## Features

- Add tasks (button or Enter key)
- Mark tasks complete/incomplete
- Delete tasks
- Live count of remaining tasks
- Tasks persist across page refreshes

## Getting started

```bash
npm install
npm run dev
```

## Project structure

```
src/
  App.jsx       - main app state & layout
  TaskItem.jsx  - single task row
  App.css       - app styles
  index.css     - global reset/theme
```
